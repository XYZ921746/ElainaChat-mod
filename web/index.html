✦ 对话模型

聊天、记忆整理、Agent 等全部请求都走默认模型。

默认模型请求失败（限流 / Key 失效 / 网络等）时，按此顺序逐个尝试。

请求由本机直接发往各服务商，不经过作者服务器；Key 只保存本机（Android 走系统 Keystore）。

图片转述（可选） 默认模型本身能识图时不要打开；只有纯文本模型才需要一个视觉模型替它看。

💡 主模型本来就支持查看图片（多模态）时，建议不要打开这个开关 —— 图片直接交给它，细节更全、速度更快。只有主模型是纯文本时，才需要在这里接一个视觉模型替它看。

图片转述就用这里选中的模型；它的 API 地址与 Key 直接取该提供商在「对话模型」里配好的那一份，不用另填。

✦ 语音输出（多服务商）

必填，1-4 句：性别与年龄、音色质感、情绪语气、语速节奏。越具体越贴近预期，避免相互矛盾或加混响 / EQ 类描述。

⚠️ 开启「完全访问」意味着
  • · AI 能读写任意路径的文件，并能执行 PowerShell / cmd 命令。
  • · AI 能删除文件与目录（del / Remove-Item 等），不进回收站、无法恢复；也能改注册表、关机、下载并执行网上的脚本。

  • · 这些操作都不会再询问你 —— 这是这一档的定义。

✦ 访问密码（局域网）
检测中…

未设密码时只有本机（127.0.0.1）可用；设了密码后本机与局域网设备都要输入密码。忘记密码只能删掉数据目录下的 auth.json 再重启（登录页的「忘记密码？」会显示实际路径）。

⚠️ 关于这个密码的分量
  • · 登录后的设备与本机同等能力（读写任意文件、执行 PowerShell / cmd），所以这个密码是整台电脑的钥匙。
  • · 强度要求：≥8 位且同时含数字、小写、大写；弱口令、键盘顺子（qwerty）、"弱口令 + 数字尾巴"都会被拒。
  • · 已内置防爆破与全局限流：密码错会逐次延长锁定（30 秒起翻倍，最长 1 小时，失败次数只在登录成功后清零）；换 IP 持续攻击会让全部登录临时冻结。

Extensions

扩展

宿主只保留对话本体。插件、技能与 MCP 服务按需装卸，失败时只影响它自己。

✦ 插件（Mod）

可选功能的开关。安装插件等于信任它的代码（它在页面同源环境里运行），请只装自己信得过的。 拖插件卡片到某个分栏的标题上可以归类；拖分栏标题本身可以调分栏顺序。

✦ 技能（Skill）

技能是给 AI 的指令与知识（一个含 SKILL.md 的目录），与插件相互独立。 本地技能可以卸载；插件随附的技能住在插件目录里，会随插件一起删掉。

✦ MCP 服务器

MCP 是外部工具服务：本应用当客户端去连它，把它提供的工具并进 AI 的能力清单。 它在你的页面之外运行（一个本地进程），能力大小取决于那一端做了什么 —— 只加自己信得过的服务器。
