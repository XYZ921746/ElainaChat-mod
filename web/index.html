测试报错对照

模型只能填非流式的 qwen3-asr-flash / qwen-audio-3.0-asr-flash；带 -streaming 的走 WebSocket，本应用调不了。

401 = Key 无效或未开通；403 / 404 = 模型未开通；400「format is empty」= 请求体形状不对（应用已按模型自动适配）；400「ASR_RESPONSE_HAVE_NO_WORDS」= 音频里没人声（测试发的是静音，属正常）。

✦ 对话优化

联网搜索
需要最新信息时让 AI 自己去搜一下，再把结果当作资料回答。用的是你自己的搜索额度。

支持 {{query}} 与 {{count}} 两个占位符。留空则发 {"query":…,"count":…}。

留空会自动在返回里找出结果数组（title/name、url/link、content/snippet 这些常见字段名都能认）。找错了再填这里。

第三人称（两段式生成）
先以旁白视角推进剧情，再改写成伊蕾娜的第一人称口吻展示给你。

开思考时部分服务商不支持自定义温度，会自动省略该参数。

图片转述（视觉模型）
用一个额外的多模态模型先把图片转述成文字，再交给主模型回答。

💡 主模型本来就支持查看图片（多模态）时，建议不要打开这个开关 —— 图片直接交给它，细节更全、速度更快。 只有主模型是纯文本时，才需要在这里接一个视觉模型替它看。

✦ AI 权限
控制 AI 通过 [操作:…] 标签能做什么。前三档同时管电脑与手机；「关闭」只关电脑侧（手机侧另有开关）。
⚠️ 开启「完全访问」意味着
  • · AI 能读写任意路径的文件，并能执行 PowerShell / cmd 命令。
  • · AI 能删除文件与目录（del / Remove-Item 等），不进回收站、无法恢复；也能改注册表、关机、下载并执行网上的脚本。
  • · AI 能覆盖已有文件，原内容不会自动备份。
  • · 这些操作都不会再询问你 —— 这是这一档的定义。
  • · 局域网设备登录后同样能用这个模式（与本机同等能力），访问密码是唯一防线。请只在你可控、且信任当前对话内容时开启。
ℹ️ 三档共有的说明
  • · 三档都能访问任意路径；读取任何档位下都不会询问 —— 包括 data/store.json（含 API Key 明文）。
  • · 「自动通过」档只禁删除、不禁覆盖 —— 覆盖同样会丢原内容，写同名文件即可绕过删除禁令。

它能看到什么、能做什么
  • · 能：打开 http / https 网址、读页面文字、点按钮和链接、往输入框打字、按回车。

⚠️ 关于这个密码的分量
  • · 登录后的设备与本机同等能力（读写任意文件、执行 PowerShell / cmd），所以这个密码是整台电脑的钥匙。
  • · 强度要求：≥8 位且同时含数字、小写、大写；弱口令、键盘顺子（qwerty）、"弱口令 + 数字尾巴"都会被拒。
  • · 已内置防爆破与全局限流：密码错会逐次延长锁定（30 秒起翻倍，最长 1 小时，失败次数只在登录成功后清零）；换 IP 持续攻击会让全部登录临时冻结。
