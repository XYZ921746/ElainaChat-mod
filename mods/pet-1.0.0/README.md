# 桌宠

悬浮在桌面上的角色：立绘 + 聊天气泡，AI 回复时自动切换表情。

## 依赖

**需要先启用「伊蕾娜立绘与情绪」**（`elaina-avatar`）—— 立绘与情绪识别与 Galgame **共用同一份**。
缺这个前置时本插件会被**拒绝加载**。

## 怎么用

1. 设置 → 插件 → 打开「伊蕾娜立绘与情绪」与「桌宠」两个开关
2. 桌面上出现悬浮角色（可拖动）

## 特性

- **情绪自动切换**：AI 回复的情绪决定用哪张立绘（走 `elaina-avatar` 的词表，与 Galgame 同源）
- **主动搭话**：可让 AI 看你正在做什么（前台窗口 + 进程），然后主动说一句
  （需要服务端的"看电脑在干什么"能力，仅电脑版可用）
- 气泡里可以直接回复

## 技术说明

- `index.js`：悬浮层与气泡
- `style.css`：样式
- 立绘走 `host.require('elaina-avatar')`，不自己拼路径

桌宠的"主动搭话"用的是宿主既有链路（`host.sendUserMessage`），
所以记忆、续跑、停止、语音都会自动生效 —— 与从主输入框发消息是同一条路。

## 已知限制

- 关掉桌宠会**停掉主动搭话**的定时器（看不见的宠物不该在后台发消息）
- 主动搭话有冷却时间，避免刷屏
