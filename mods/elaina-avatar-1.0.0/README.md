# 伊蕾娜立绘与情绪

**公共依赖插件**：提供一套立绘 + 一套情绪词表，被「Galgame 界面」与「桌宠」共用。
它自己**不提供任何界面**（所以列表里标着"公共依赖"）。

## 为什么单独做成一个插件

上游 v1.3.1 里 Galgame 与桌宠**各自实现了一份**立绘路径与情绪词表，而且资源也重复：

| | 上游 | 本插件 |
| --- | --- | --- |
| 立绘 | 3 套共 30.8 MB（其中 9/9 张与另一套逐字节相同，另一套零引用） | **1 套 9 张 10.3 MB** |
| 情绪词表 | 两份代码各写一份 | **一份** |

所以它既消除代码分叉（改词表只改一处，两个界面同时生效），也消除资源重复。

## 对外接口

挂在 `window.ElainaAvatar`，两个界面插件通过 `host.require('elaina-avatar')` 取：

| 方法 | 说明 |
| --- | --- |
| `EMOTIONS` | 情绪键数组（9 个：smirk / shy / calm / surprised / resigned / speechless / angry / confused / happy） |
| `LABELS` | 键 → 中文名 |
| `fromText(text)` | 从文本识别情绪键，识别不到返回 `null` |
| `src(key)` / `url(key)` | 情绪键 → 立绘 URL（未知键回落到 `calm`） |
| `isReady()` | 立绘资源是否可用 |

## 资源基址

**不要**自己拼 `/mods/elaina-avatar/img/…` —— 插件声明的 `id` 与实际安装目录名**可能不同**
（历史版本装出过 `elaina-avatar-1.0.0/` 这种目录，写死路径会全部 404）。
用 `host.require('elaina-avatar').url('img/p_calm.png')`，路径由插件系统按真实目录算。

## 已知限制

- 立绘 9 张（`img/` 目录）**不入库**，走 Releases 分发；装的是"纯净版"APK 时需要单独下载
- 情绪词表是中文关键词匹配，不含语义理解 —— 识别不到时由调用方决定回落成什么
