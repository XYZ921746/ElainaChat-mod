# 02 快速开始与模板

目标：产出一个能加载、能被用户开关、卸载不留残留的最小插件。

## 一、目录长什么样

```text
mods/<安装目录>/
├─ manifest.json        ← 必需：清单
├─ index.js             ← 入口（默认名），里面有 ElainaMods.register
├─ style.css            ← 可选：清单里声明了才会随开关启用 / 停用
├─ README.md            ← 可选：用户点卡片上的「说明」看到的就是它
└─ img/ …               ← 可选：插件自己的资源
```

`<安装目录>` 是**安装时的包名**（例如 `my-plugin-1.0.0`），不要求和 `manifest.id` 一致。

## 二、最小 manifest.json

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "description": "一句话说明它做什么。",
  "entry": "index.js",
  "defaultEnabled": false
}
```

字段细节（`scripts` / `styles` / `after` / `hidden` / `capabilities` / `skills` / `server`）见 `03-契约速查.md` 的 A1。
**默认关闭**是刻意的：只有显式写 `"defaultEnabled": true` 才算默认开。

## 三、最小 index.js

```js
/* 工厂只做注册：不发请求、不起定时器、不改别人的 DOM（AGENTS.md D6）。
 * 想立刻生效的东西就登记成贡献；需要动作的，放进 setEnabled 或按钮回调。 */
(function () {
    'use strict';

    const MOD_ID = 'my-plugin';

    window.ElainaMods.register(MOD_ID, function (host) {
        // ① 登记：设置里占一栏（点开时才渲染）
        host.slot('settings.tabs', {
            id: MOD_ID,
            label: '我的插件',
            render(container) {
                const p = document.createElement('p');
                p.textContent = '你好，这里是「' + host.manifestId + '」。';
                container.appendChild(p);
            },
        });

        // ② 状态：走 host.storage（别用 localStorage）
        const st = Object.assign({ on: true }, host.storage.get('state', {}));
        const save = () => host.storage.set('state', st);

        // ③ 返回 api：宿主在启用 / 停用时回调 setEnabled；调试入口也放这里
        return {
            setEnabled(on) {
                if (on) {
                    host.log('已启用');
                } else {
                    host.log('已停用');
                }
                st.on = on;
                save();
            },
        };
    });
})();
```

要点：

- 工厂**同步返回** api 对象（可以是 `{}`）。返回的东西会挂在插件条目上，
  别的插件经 `host.require('my-plugin').api` 就能拿到。
- 不要在工厂里读 `document.body` 或往宿主元素里塞 DOM；要用插槽。
- 启动时机：需要"存储读完 / 应用初始化完"再动手时，用 `host.on('app-ready', fn)`。

## 四、要"一启用就做事"怎么办

工厂只做注册，但你可以把动作交给 `setEnabled(true)`：

```js
return {
    setEnabled(on) {
        if (on) startWatch(); else stopWatch();
    },
};
```

宿主会在启用（含刷新后自动恢复启用）与停用时各调一次。
**注意**：停用后再启用**不会重跑工厂**——所以工厂里建的变量 / 定时器要先判空再建。

## 五、给用户写 README.md

插件卡片上的「说明」按钮读的是插件目录里的 `README.md`（文件名白名单：`README.md` / `README.txt` / `README` / `说明.md`，上限 256KB）。
写：这个插件做什么、怎么用、有什么限制。**不要**把开发规范写进去。

## 六、常见坑（都属于"看起来 ready 但没效果"）

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 插件 ready，界面没有 | 在工厂里直接操作 DOM / 忘了用插槽 | 改成 `host.slot(...)` |
| 双份界面、双份定时器 | 工厂里起了定时器，启用时又 `setEnabled(true)` 起了一次 | 定时器只在 `setEnabled` 里起，并且判空 |
| 资源 404 | 自己拼 `/mods/<id>/img/x.png` | 用 `host.assetUrl('img/x.png')` |
| 设置刷新就丢 | 用了 `localStorage` / 自造键 | 用 `host.storage` |
| 开关关了还在影响模型 | 直接改了提示词字符串 | 用 `host.setPromptHint`，停用会被摘掉 |
| 点按钮没反应 | 在 `host.on('点我')` 上等一个宿主根本不发的事件 | 事件清单见 `03` 的 A2 末尾 |

## 七、打包与安装

1. 把插件目录里的文件打成 zip（zip **根层**直接是 `manifest.json`、`index.js`…，
   或者带一层与插件同名的目录——两种都会被认）。
2. 命名建议 `<id>-<version>.zip`；**zip 文件名决定安装目录名**（会剥掉尾部版本号）。
3. 应用内：设置 → 插件 → 「上传安装」选这个 zip；或直接把 zip 放进 `mods/` 目录，服务端扫描时自动解压。
4. 打开插件开关验证。加载失败时，卡片上会写明原因并自动停用。
