# 03 契约速查

从 `AGENTS.md` 的契约表搬来的**可复制摘要**。契约变了以 `开发文档.md` 的表 A 为准。

## A1 manifest.json 字段全集

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | **身份**。须匹配 `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`；缺失 / 非法时回落到目录名 |
| `name` | string | 显示名 |
| `version` | string | 版本号 |
| `description` | string | 一句话说明（插件卡片用） |
| `entry` | string | 入口脚本，默认 `index.js` |
| `scripts` | string[] | **额外脚本，按顺序注入**；`entry` 最后注入 |
| `styles` | string[] | 样式表，随启用 / 停用真正生效 / 失效 |
| `defaultEnabled` | boolean | **只有显式 `true` 才算默认启用**；漏写 = 关闭 |
| `after` | string[] | 前置插件 id 列表。前置不可用时本插件**拒绝加载**（`blocked`） |
| `hidden` | boolean | 公共依赖：设置页的「前置扩展」区，仍可单独开关 |
| `capabilities` | string[] | **前端** host API 能力组：`theme` / `achievements` / `dragSort` / `openFolder`（`core` 永远有） |
| `skills` | string[] | 随附技能的相对路径，如 `["skills/xxx"]` |
| `server` | object | 服务端半边声明，见 A6；没有就不写 |

注意 `scripts` 与 `entry` 的注入顺序：`scripts` 先、`entry` 后 —— 装配文件要调用别的文件定义的东西。
`register()` **只能在某个插件脚本注入期间调用**，脚本加载完再调会被拒绝。

## A2 host API 成员

工厂参数 `host` 上的成员：

| 成员 | 说明 |
| --- | --- |
| `id` | 注册名 |
| `manifestId` | 清单里的 `id`（可能与注册名不同） |
| `pluginVersion` / `version` | 插件自己的版本（`version` 是历史字段，新代码用 `pluginVersion`） |
| `hostVersion` | 宿主契约版本，用来做兼容判断 |
| `signal` | `AbortSignal`：插件被**卸载 / 删除**时 abort（临时停用不 abort） |
| `service(name, api)` | 注册插件服务；宿主用 `ElainaMods.service(name)` 取（只返回已就绪插件） |
| `assetUrl(rel)` / `assetBase()` | 本插件资源的 URL；越界 / 外链返回空串 |
| `require(key)` | 按注册名 / 清单 id / 目录名查别的插件 → `{ ok, reason, id, dir, regName, api, url, base }` |
| `log(...)` / `warn(...)` / `error(...)` | 带 `[Mod:<注册名>]` 前缀的日志 |
| `getConversation()` / `getMessages()` / `getUiMode()` | 当前对话、消息列表、界面模式 |
| `sendUserMessage(text)` | 以用户身份发一条消息，走宿主同一条链路（记忆 / 续跑 / 语音都生效）；无当前对话时返回 `false` |
| `renderText(text)` | 用宿主的 Markdown 渲染器出 HTML |
| `alert(msg, title)` / `confirm(msg, title)` | 宿主风格的弹窗 |
| `openSettings(id)` / `hasSettings(id)` | 打开 / 查询**另一个插件**的设置窗 |
| `storage` | 插件私有存储：`get/set/remove/keys/all`，单插件上限 1MB，超限 throw |
| `slot(name, spec)` / `slots()` | 往插槽注册 / 列出可用插槽 |
| `injectStyle(href)` | 注入插件自己的样式表（相对路径，停用真正失效） |
| `setPromptHint(text)` / `clearPromptHint()` | 往 system 提示词追加 / 摘掉一段（**同一插件是覆盖语义**，不是拼接） |
| `on(event, fn)` / `emit(event, detail)` | 宿主事件订阅 / 广播；停用会摘掉订阅 |
| `has(name)` / `capabilities()` / `grantedGroups()` | 能力探测与自查 |

**按能力组下发**（A22）：`openFolder(sub)`（组 `openFolder`）、`dragSort(container, onDone)`（组 `dragSort`）、
`theme(spec)`（组 `theme`）、`unlock(id, detail)`（组 `achievements`）。
**没在 `manifest.capabilities` 里声明时，这些成员根本不存在**（不是空函数）—— 误用会当场 TypeError。

`host.theme(spec)` 返回 `{ ok, id, use(), restore() }`：`use()` 临时切到这套主题，`restore()` 还回用户原来的。

**宿主会广播的事件**（用 `host.on` 订阅）：

| 事件 | 载荷 | 时机 |
| --- | --- | --- |
| `app-ready` | `{ announcementPending }` | 存储读完、应用初始化完成（晚注册的插件也会补调） |
| `announcement-closed` | `{}` | 首次公告被用户关掉 |
| `mod-changed` | `{ id, enabled }` | 某个插件的开关变了 |
| `voice-energy` | `level`（数字） | 宿主说话时的音量，用于口型 |

不要在插件之间自造事件名并通过宿主广播 —— 那等于私有全局名的另一种写法（D4）。
插件之间要协作，用 `host.require(id)` 拿对方的 api。

## A5 宿主插槽（只有这 6 个）

| 插槽 | spec 形状 | 形态 |
| --- | --- | --- |
| `settings.tabs` | `{ id, label, title?, render(container) }` | 普通；**点开才渲染**；撞 id 即拒绝 |
| `settings.modal` | `{ id, label, title?, render(container), onOpen?, onClose? }` | 普通；插件卡片齿轮打开，每插件一个专属窗口 |
| `header.actions` | `{ id, label?, title?, svg?, onClick(ev) }` | 普通；顶栏按钮，`onClick` 必填 |
| `sidebar.footer` | `{ id, render(container, ctx) }` | 普通；侧栏底部一块区域 |
| `composer.actions` | `{ id, render(container, ctx) }` | 普通；输入框那一行的按钮位 |
| `chat.message.actions` | `{ id, render(container, item) }` | **每项级**：每条消息标题行；`item = { message, conversationId }` |

规则：

- `host.slot()` 返回句柄 `{ el, dispose() }`。**通常不用自己 dispose** —— 停用 / 卸载时系统统一回收。
  只有"插件还在、但这一项不要了"时才手动调。
- 普通插槽的 `render` **可能被重复调用**（停用再启用会重新挂载），所以要能从空容器重建。
- 容器型插槽里画进去的元素会被打上 `data-mod`，停用时只摘这些，不碰别人的东西。
- 拿不准插槽名：`host.slots()` 列出宿主当前提供的插槽；写错名字会在日志里列出可用插槽。
- **不要另开插槽**：需要新位置就得改宿主，那是宿主开发者的事，不是插件作者的。

## A6 manifest.server 声明

```json
{
  "server": {
    "entry": "server.mjs",
    "capabilities": ["route-register", "static-read", "host-utils"],
    "routes": ["/api/my-plugin"],
    "uploads": ["my-uploads"],
    "static": [{ "url": "/my-plugin/assets", "dir": "assets", "mime": "auto" }]
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `entry` | 必填，`.js` / `.mjs`，不得含路径成分或 `..` |
| `routes` | 路由前缀数组（如 `/api/my-plugin`），不得重复 |
| `uploads` | 用户上传目录名数组（相对插件目录） |
| `static` | URL 前缀 → 插件目录内子目录；`mime: "auto"` 才按真实 MIME 返回 |
| `capabilities` | 服务端能力名，见 A23；**取用时没声明会 throw** |

## A23 服务端能力名

| 能力 | 允许做什么 |
| --- | --- |
| `route-register` | `ctx.route(method, path, handler)`，且必须落在 `routes` 声明内 |
| `upload-write` | `ctx.uploadDir(rel)`，读写 `uploads` 声明的目录 |
| `static-read` | `ctx.staticDir(url)`，读 `static` 声明的目录 |
| `host-utils` | `ctx.utils`（宿主共享工具，含解压） |
| `net-outbound` | 自己发外部网络请求 |

能力名写错 / 重复 / 与 routes·uploads·static 不自洽 → 整份声明被驳回，**该插件的服务端半边不装载**。

## A3 / A4 状态词汇（用户会看到的字）

前端状态：`ready`＝「已加载」、`disabled`＝「已关闭（未启用）」、`blocked`＝「已拒绝加载（前置插件不可用）」、
`error`＝「加载失败」、`pending`＝「加载中」。

插件错误**只出现在插件卡片上**（角标 + 明文原因），不要自己弹全局 alert 报插件自身的错误。
