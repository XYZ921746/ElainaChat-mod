# 制作插件（Mod）

本技能是**按需渐进加载**的：这一页只给路线图与红线，细则都在下面列出的文本里。
用到哪一节，就**只读那一节**，不要一次把整份说明读完。

## 零、先确认这是不是插件

| 你想做的东西 | 应该做成 | 说明 |
| --- | --- | --- |
| 改界面、加按钮、加面板、加资源、调宿主能力 | **插件（mod）** | 本技能管的就是它 |
| 教 AI 一段知识 / 固定套路 / 让 AI 调舞台背景与表情 | **技能（SKILL.md）** | 纯文本资料，放 `skills/<id>/SKILL.md`，不进应用、不可执行 |
| 只是想改聊天行为、加系统提示词段落 | 角色卡 / 记忆 / 插件里的 `host.setPromptHint` | 不要为此改宿主 |

插件是``"可装可卸的第三方代码"``——它在**同源下执行任意 JS**，所以"不要为了自己的插件去改宿主"。

## 一、渐进加载规则（**必须遵守**）

1. 先读**本文件**（你在读的这一页）→ 得到路线图与红线。
2. 动手写代码前，按下面的索引**只读你需要的那几节**。
3. 不用的章节**不要读**：每读一节就是一次额外的上下文开销，普通对话里不该付这个代价。
4. 读过的结论如果和代码对不上，以 `AGENTS.md` 的「判定」栏与源码为准，并回来看 `05-零错误清单.md`。

## 三、绝对路径（按需读取用）

本技能的根目录：

```text
skills/mod-authoring-guide/
```

把它和本机项目根拼起来就是完整路径。例如项目根是 `D:\222\ElainaChat-mod`：

```text
D:\222\ElainaChat-mod\skills\mod-authoring-guide\02-快速开始与模板.md
D:\222\ElainaChat-mod\skills\mod-authoring-guide\03-契约速查.md
D:\222\ElainaChat-mod\skills\mod-authoring-guide\04-持久化资源与服务端.md
D:\222\ElainaChat-mod\skills\mod-authoring-guide\05-零错误清单.md
```

怎么读：用 Agent 的 `read_file`（工具名）读**绝对路径**。
先读 `02`（骨架）→ 写完 `manifest.json` 再读 `03`（字段怎么填）→ 要存东西读 `04` → 最后读 `05` 收尾。

## 四、红线（任何一节都没读也必须记住）

- **D1** 不要自己拼 `/mods/` 路径。目录名和 `manifest.id` **可以不一致**，自拼路径在目录改名后必 404。用 `host.assetUrl()` / `host.assetBase()`。
- **D2** 不要用 `localStorage`。持久化只走 `host.storage`（落 `data/`、跨设备同步）。
- **D4** 不要用 `window.__xxx` 这类私有全局名在插件之间传东西。用 `host.require(id)` + 对方返回的 api。
- **D6** 插件工厂**只做注册**：不发请求、不启动定时器、不改别人的 DOM。动作放在工厂返回的 `{ setEnabled() }` 或用户点击之后。
- **D8** 注释只写"为什么"，不要写变更史（`原先` / `旧版` / `第一版` …）。
- **纯文本**：技能与插件都是同名同姓的两回事，不要把 `SKILL.md` 放错位置。

违反任一条，插件在用户机器上出现的问题分别是：资源 404（D1）、刷新即丢设置（D2）、加载顺序不可见（D4）、"ready 但界面全无 / 双份定时器"（D6）。

## 五、一句话流程

```text
想清楚做什么 → 读 02 建骨架 → 读 03 填 manifest → 写 index.js（工厂只做注册）
→ 要存数据 / 要资源 / 要服务端 → 读 04 → 读 05 自查 → 打包 zip → 应用内「设置 → 插件 → 上传安装」→ 打开开关验证
```

## 六、验证时看哪里

- 设置 → 插件：卡片上的状态（已加载 / 已关闭 / 已拒绝加载 / 加载失败 / 运行期已出错 N 次）。
- 控制台：`[Mod:<注册名>]` 前缀的日志。
- 插件卡片上的「说明」按钮读的是插件目录里的 `README.md`——给用户写用法，**不要**把规范塞进去。
