# ElainaChat 可运行重构版

这是从 `ElainaChat-mod` 复制出来的**独立运行副本**：后端、真实前端逻辑、插件与技能都在本目录，原项目没有被修改；新视觉层已经接到这份副本上。

布局按根目录原型的方案对齐：**全屏应用、无居中 1440×900 外框、76px 竖栏 + 316px 对话列表、顶栏不占行情胶囊、设置是整页**。列表补了消息预览/时间，顶栏补了副标题和模型胶囊，竖栏补了账户头像，右下角有设计实验室入口。

- `web/css/layout-full.css`：全屏布局与上述组件的覆盖层。
- `web/css/pages-luxe.css`：语笺/日记的书卷式排版、成就/市场的整页 hero、设置页细节。
- `web/js/redesign-extras.js`：模型胶囊/副标题、设计实验室按钮、日记统计条、成就进度 hero 的接线。
- 默认主题为**暗夜魔女书房 · 深色**，顶栏可切换浅色/深色/跟随设备。

## 页面形态

- **语笺**：KEEPSAKES 页头、金色收藏卡、空状态的星环。
- **旅行日记**：TRAVEL JOURNAL 页头、篇数/字数/分组统计、金色时间线与书卷卡片。
- **成就**：主区整页（保留左侧对话栏），MILESTONES 页头 + 进度环 + 已解锁/未解锁徽章网格。
- **插件市场**：入口在「设置 → 插件 → 插件市场」（竖栏不设入口），主区整页（保留左侧对话栏），MOD MARKET 页头 + 精选 hero、搜索、双列扩展卡与商店源。
- **设置**：主区整页（保留左侧对话栏），PREFERENCES/设置页头、左侧图标分栏、2×2 主题卡、显示卡片（模式/气泡形状/背景光晕/当前主题）；设置打开时点侧栏导航会自动收起。
- 主题卡、模式、气泡形状、背景光晕都即时生效；模式与顶栏开关双向同步。

## 启动

```bash
# 在本目录下
node start.mjs
# 浏览器打开 http://127.0.0.1:4100
```

Windows 也可以直接双击 `启动.bat`（会自动打开浏览器）。

默认端口 **4100**，与原来运行在 **3999** 的应用互不影响。两个应用各用各的数据目录。

## 目录

```
app/
├─ web/       复制来的真实前端 + 四套新主题（布局覆盖：css/layout-full.css；增强：js/redesign-extras.js）
├─ server/    复制来的本地后端
├─ mods/      复制来的插件
├─ skills/    复制来的技能
├─ data/      启动时从原项目复制的数据快照
├─ start.mjs  启动入口（PORT=4100）
└─ 启动.bat   Windows 双击启动
```

## 说明

- **原项目只读**：`D:/222/ElainaChat-mod` 里的代码、data、mods 不会被这个副本写入。
- `data/` 是创建副本时的一份快照，之后两个应用的数据各自独立；想用干净实例的话，删除 `data/` 后重新启动即可（服务会重建目录）。
- 四套主题在 **设置 → 外观**：暗夜魔女书房（默认）/ 现代极简 / 雾蓝日系 / 石墨玻璃；顶栏的跟随设备 / 浅色 / 深色仍然有效。
- 局域网访问密码在启动窗口打印，也可以之后在「设置 → 高级」修改。
- 不需要 `npm install`；需要 Node.js >= 20。
- 上一级的 `D:/222/ElainaChat-redesign` 根目录仍是纯静态设计原型，和这份可运行副本分开。
