# ElainaChat mod

本地优先的 BYOK AI 角色聊天应用。程序本体只内置**文字聊天 + Agent 能力**，角色的呈现方式与界面细节交给**可装可卸的扩展包（mod）**：宿主不认识任何具体插件，插件只通过一份收窄的 host API 与固定的宿主插槽接入。

- **零依赖、免构建**：克隆下来 `node start.mjs` 就能跑（Node.js ≥ 20），不需要 `npm install`，也没有构建步骤。
- **BYOK，数据全在本机**：接入你自己的大模型 API Key，请求从本机直接发给服务商；没有作者网关、共享套餐或内置密钥。
- **mod 优先**：扩展包决定立绘、Live2D、桌宠、场景背景、情景演绎（galgame）等呈现；装了坏插件会被隔离并写盘自动停用，只在那张插件卡片上说明原因，不影响宿主与其它插件。
- **Agent 操作**：模型可以读写文件、执行命令、操作手机（点击 / 滑动 / 输入 / 截图 / 读通知短信通讯录日历）、写日记记忆（如 `recall_search` 凭日记找回历史原话）、创建定时任务；操作说明书按需下发，权限分档。
- **AI 联网搜索与浏览器**：需要"现在的事实"时 AI 自己去搜（内置 **Tavily**，另有**自定义搜索源**），或者真的开一个独立浏览器窗口看页面、点按钮、填表单。
- **MCP 客户端**：在「设置 → 扩展 → MCP」里加一台 MCP 服务器（一条启动命令即可），它提供的工具会自动出现在 AI 的能力清单里。只做客户端方向 —— **不会**把本机的文件与命令执行能力暴露出去。
- **语音**：云端 ASR 识别（阿里百炼 / 小米 MiMo）与多服务商 TTS（MiMo / MiniMax 克隆音色 / 千问 Qwen-TTS / 兼容 OpenAI TTS）。
- **自带访问控制**：局域网设备接入需要访问密码，设置密码后本机打开应用也要输入；没设置密码时局域网接口直接关闭、只有本机可用。密码有强度校验与三层防爆破，服务端同时支持 HTTPS 自签证书（手机端语音输入要用）。
- **数据备份与局域网共享**：在「高级 → 我的数据」导出 / 导入标准 zip（`data/` + `mods/` + `skills/`）；同一局域网的两台设备也能直接开启共享、用 IP / 端口与访问密码互相拉取，不必先拷文件（需先设置访问密码）。
- **版本检测**：设置 → 高级「版本与更新」直接查 GitHub 仓库的最新 Release；按当前运行形态（手机版 APK / 桌面版 exe / 电脑版源码）给出对应安装包，**只提示与下载，不自动替换程序**。GitHub 被 hosts / DNS 指偏时自动改用公共 DNS 解析真实 IP 直连（证书仍按 api.github.com 校验，不改系统设置）。
- **PWA**：浏览器打开后点顶栏「安装」，即可装成桌面独立应用。

## 特性

- **人设与对话**：一张人设卡一文件，可新建 / 复制 / 改名 / 删除并随时切换；消息渲染支持 Markdown 与 LaTeX（公式走 KaTeX，渲染器自带转义，原始 HTML 一律当字面量）。
- **记忆**：每过若干轮自动写一篇日记（也可以点「立即整理记忆」手动整理），聊天时按需检索；另有金句 / 语笺 / 收藏。
- **四套主题**：暗夜魔女书房（默认）/ 暖米绿 / 雾蓝日系 / 石墨玻璃；显示模式另有**浅色 / 深色 / 跟随系统**三档。
- **定时任务**：对 AI 说"每天给我发消息 / 明天提醒我…"，它用 `[任务:…]` 建立任务，到点以角色身份主动给你发消息。
- **成就系统**：事件成就（如 10 月 17 日「星屑之日」生日纪念）与进度成就两类，解锁后持久保留 —— 删掉几段对话，已拿到的成就也不会被撤销。
- **BYOK 直连**：支持 OpenAI 兼容（DeepSeek / 硅基流动 / OneAPI / Ollama…）、Anthropic、OpenAI Responses 三种对话协议，可填自己的 Base URL；各家 API Key 分开存。
- **AI 权限分档**：「关闭 / 逐条确认 / 自动通过（禁止删除）/ 完全访问（含删除）」四档，前三档同时管电脑与手机。
- **局域网访问**：手机 / 平板用局域网地址打开，凭启动窗口打印的访问密码登录；本机（127.0.0.1）免密。
- **软件内日志**：日志按级别与模块查看、可导出；敏感字段（含 API Key）落盘前脱敏。

## 下载与安装

到 [Releases](https://github.com/XYZ921746/ElainaChat-mod/releases/latest) 下载对应平台的包：

### 电脑版（WebView2 外壳，推荐）

下载 `ElainaChat-Setup.exe` 安装，或直接解压便携版 zip。安装包会创建开始菜单与桌面快捷方式，卸载时可以选择保留聊天数据；**不需要**安装 Node.js，也**不需要**构建。包内结构：

```text
ElainaChat/
├─ ElainaChat.exe     # WebView2 外壳：自动拉起内置 node 并打开界面，托盘常驻
├─ node/node.exe      # 随包携带的 Node 运行时
├─ shell.json         # 外壳配置（入口 start.mjs、端口）
├─ app/               # 程序本体（web/ server/ scripts/ …）与 app\data\
└─ README.md          # 便携版使用说明
```

- 数据在 `app\data\`，与服务日志 `app\logs\node.log` 一起随目录移动。
- 关闭窗口 = 最小化到托盘，托盘右键「退出」才是真正退出；任务管理器只需结束 `ElainaChat.exe` 一个，后台服务随之退出。
- 外壳依赖系统的 WebView2 运行时（Windows 10/11 一般自带；缺失时外壳会提示初始化失败）。

### 安卓版

下载 `ElinaChat-mod-x.y.z.apk`（仅 arm64-v8a；debug 构建另带 x86_64 供模拟器用），在手机上允许「安装未知来源应用」后安装。APK 把 `web/` 打进 WebView，并在 `:node` 独立进程里内嵌 Node 运行时来承载需要服务端的那部分能力 —— 是否打包 Node 由构建开关 `ELAINA_NODE_RUNTIME` 决定，关掉时前端自动回落到原生实现，APK 体积也会小很多。

> 包名与发布文件名可能随版本调整，**以 Releases 页面实际列出的文件为准**。

## 从源码运行

```bash
node start.mjs
# 浏览器打开 http://127.0.0.1:3999
```

- 需要 Node.js ≥ 20；**不需要** `npm install`，也没有构建步骤。
- 默认端口 **3999**，被别人占用时自动往上找（4000、4001…）；显式传 `PORT` 时按给定端口启动，占用即报错。
- 本项目的另一个实例已经在跑时，不会再起一个服务，只把浏览器指过去然后退出。
- Windows 也可以直接双击 `启动.bat`（会自动打开浏览器）。
- 数据目录 `data/` 首次启动自动生成；想用干净实例，删除 `data/` 后重启即可。

## 装成桌面应用（PWA）

用 `http://127.0.0.1:3999` 打开（用局域网 IP 打开时浏览器不给安装入口，这是安全上下文规则），顶栏会出现「安装」按钮，点一下装成独立窗口的桌面应用。它与浏览器版读写同一份 `data/` —— 服务得在跑，PWA 不是独立后端。卸载只删快捷方式，不动数据。

## 双端能力对比

| 能力 | 电脑版 | 安卓版（APK） |
|---|---|---|
| 文字聊天 / 语音 / 主题 / 人设 / 成就 | 支持 | 支持 |
| AI 操作电脑（读写文件 / 执行命令） | 支持（可访问任意路径，按权限档决定问不问） | 不支持 |
| AI 操作手机（点击 / 滑动 / 输入 / 截图 / 读通知短信通讯录日历） | 不支持 | 支持（读取类信息按「能力」页的隐私开关逐项授权） |
| AI 读写手机文件 | 不支持 | 支持（Agent 工作区 + 你授权的一个文件夹） |
| 插件安装 / 卸载 | 支持（丢进 `mods/`、应用内市场或「上传安装」） | 支持（只能应用内市场 / 「上传安装」） |
| 插件的服务端半边（`manifest.server`） | 支持（`web/serve.mjs` 装载） | 支持（内嵌 Node 装载同一份 `server/mod-server.mjs`；未打包 Node 时回落原生兜底） |
| AI 用浏览器 / MCP 客户端 | 支持 | 不支持（这两项依赖电脑侧的本机服务） |
| 数据备份 | 导出标准 zip：`data/`（聊天数据）+ `mods/`（插件）+ `skills/`（技能），解压即见三类 | 导出到手机存储（`data/`），可与电脑版互相导入；插件 / 技能需在电脑版恢复 |

## 扩展包（Mod）

程序本体只负责聊天与 Agent 能力，呈现方式全在扩展包里。仓库**不包含任何插件源码**：仓库只推宿主本体，插件通过「设置 → 扩展 › 插件 → ✦ 插件市场」安装，也可以「上传安装」一个 zip；电脑版还可以把 zip 丢进 `mods/`。

- **默认关闭**：只有 `manifest.json` 里**显式**写 `"defaultEnabled": true` 的插件才默认启用，漏写一律算关闭 —— 插件会改界面，不该在你不知情时生效。
- **前置依赖**：打开一个插件时，它依赖的前置插件会自动一起打开；前置没装或坏了时它拒绝启动，并在卡片上写明缺什么、该装什么。反过来，有插件正在运行时，它依赖的那个插件不能直接关闭或卸载。
- **失败隔离**：装坏的插件会被自动停用并写盘，下次启动不再重试；原因只显示在那张插件卡片上，不弹全局弹窗、不牵连其它插件。
- **写插件**：完整指南在 [`skills/mod-authoring-guide/`](skills/mod-authoring-guide/SKILL.md)（快速开始、契约速查、持久化与服务端、零错误清单）；跨边界契约、host API 与插槽清单见 [开发文档](开发文档.md)。

## 目录

```text
ElainaChat-mod/
├─ web/                     # 前端本体（唯一前端编辑入口）与本地服务入口
│  ├─ index.html            # 单页骨架
│  ├─ js/                   # 前端模块（store / core / data / agent / ui / voice / settings / mods / mcp …）
│  ├─ css/                  # 样式层：base.css 先加载，其余为主题与页面覆盖层
│  ├─ vendor/               # 宿主自带库（tailwind / marked / KaTeX / pixi 与 Live2D 运行时）
│  ├─ audio/  icons/        # 内置参考音频、PWA 图标
│  ├─ nodejs/               # 安卓端内嵌 Node 的启动骨架（电脑版不用）
│  ├─ manifest.webmanifest  # PWA 清单
│  ├─ sw.js                 # PWA 用的 Service Worker（故意不缓存任何东西）
│  └─ serve.mjs             # 本地服务端与静态根
├─ server/                  # 零依赖服务端模块（数据落盘 / 插件宿主 / 中转 / MCP / 浏览器 / 日志 …）
├─ scripts/                 # 只放验证脚本：npm run check 跑的 check-*.mjs + 共用运行时
├─ skills/                  # 技能目录（给 AI 的纯文本指令与知识）
├─ mods/                    # 扩展包安装位（插件源码不入库；经应用内市场安装）
├─ data/                    # 运行时数据（主 data + 对话 data，见下）
├─ start.mjs                # 启动入口（端口策略在 web/serve.mjs）
├─ 启动.bat                 # Windows 双击启动
├─ 开发文档.md               # 架构、契约表与变更史
└─ package.json
```

- **`data/` 分两层**：`main/` 是软件级记录（设置、密钥、人设卡、记忆、音色样本），`conversations/` 是一个对话一个 JSON。`logs/`、`auth.json`、`cert.pem`/`key.pem` 是服务自身的运行件。目录图见 [`data/README.md`](data/README.md)。
- **打包不进仓库**：Windows 外壳 / NSIS 安装器 / APK 同步脚本都在本地的 `dist/` 与上一级的 `android-app/`，仓库只推宿主本体。

## 开发

- `npm run check`：运行全部检查模块，清单**以 [`scripts/run-checks.mjs`](scripts/run-checks.mjs) 为准**（`check:serial` 串行跑以便排查模块间干扰，`check:fast` 只跑插件模块）；个别依赖本机环境（插件实物、模型文件、浏览器）的用例会自动跳过。
- 可数的事实（检查模块数、扩展包数、插槽数、脚本加载数）一律**以对应文件实物为准**，本文不写死数字。
- 本地打包：`dist/Windows/build-installer.cmd` 一键产出 Windows 外壳 / 便携包 / NSIS 安装器（`dist/` 为本地目录、不入库，需本机装 Node.js）；`dist/Android/scripts/sync-web.mjs` 把 `web/` 同步进上级 `android-app/`（作为检查夹具保留在仓库内）。
- 架构说明、跨边界契约表、存量违规清单与变更史见 [开发文档](开发文档.md)。

## 隐私与数据

- 聊天记录、设置、API Key 全部存在本地 `data/`，不进仓库、不上传作者服务器；请求由本机直连你填的服务商。
- 局域网访问密码在 `data/auth.json`；本机 HTTPS 自签证书在 `data/cert.pem` 与 `data/key.pem`（首次启动自动生成）。
- 日志写入 `data/logs/`，敏感字段（含各类 API Key）落盘前脱敏；启动窗口里的访问密码不会写进日志文件。
- 手机版把数据放在应用私有目录，API Key 走 Android Keystore 加密。
