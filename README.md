一个**以插件（Mod）为核心**的开源 AI 角色聊天应用。程序本体只有文字聊天 + Agent 能力，
角色怎么呈现、界面长什么样，全都交给**可装可卸的扩展包**决定。

通过自带 API Key（BYOK）直连服务商 —— **没有作者网关、没有共享套餐、没有内置密钥**。

> **上游说明**：本项目基于 [shuixinggangzheng/ElainaChat-Open](https://github.com/shuixinggangzheng/ElainaChat-Open)（MIT 协议）二次开发。
> **上游代码已下架（仓库不再可用）**，如需了解原项目可以去看他们的官网：<https://elainachat.j3.ink/>。
> 本项目从此独立演进，MIT 许可与原作者版权声明继续保留（见文末「许可与致谢」）。

## 为什么是「Mod 优先」

大多数聊天应用把花哨功能**焊死在主程序里** —— 你不用也得装着，卸不掉，坏了还会拖垮整个应用。
本项目的取舍相反：

| | 传统做法 | 本项目 |
| --- | --- | --- |
| 新功能怎么加 | 改宿主代码 | **加一个目录**（`web/mods/<名字>/`） |
| 不想要怎么办 | 忍着，或自己改代码 | **关掉开关 / 删掉目录** |
| 插件崩了 | 整个应用白屏 | **只标记那个插件出错**，其余照常 |
| 未启用的插件 | 照样加载、占内存 | **不注入脚本、不占内存** |
| 依赖缺失 | 静默失败，界面缺一块 | **设置里标「缺依赖」+ 控制台日志** |
| 打包体积 | 全都要带上 | **纯净版约 10.8 MB**，资源按需下载 |

支撑这套说法的是具体机制，不是口号：

- **清单驱动**：加载器只认 `manifest.json`，**不硬编码任何插件名**
- **失败隔离**：插件的加载与初始化都包在 `try/catch` 里，一个坏 mod 绝不白屏整个应用
- **依赖声明 + 环形检测**：`manifest.after` 做拓扑排序，缺依赖会**明确报出来**
  （「装了 galgame 却没有立绘」这类无声故障是重点防的对象）
- **地址撞名保护**：插件要在清单里声明自己占用哪些 API 前缀与静态地址，
  与宿主撞名会被**拒绝装载** —— 宿主交出地址时必须同时从清单里删掉，两边不会各自为政
- **能力解耦**：Agent 的标签协议（文件 / 命令 / 手机操作）**不寄生在任何扩展包里** ——
  卸掉 Live2D 不会让 Agent 系统跟着失效（这条是踩过坑才补上的，见「AI 标签协议」一章）

## 下载

**安卓版**：到 [Releases](https://github.com/XYZ921746/ElainaChat-mod/releases/latest) 下载
`ElainaChat-mod-v1.3.1-lite-debug.apk`（**约 10.8 MB**），
在手机上允许「安装未知来源应用」后安装。

> **这个 APK 是「纯净版」** —— 只含程序本体 + 插件**代码**，
> **不含立绘、场景背景图与 Live2D 模型**。那些按需下载，见下方
> 「[扩展包](#扩展包mod--插件)」。

```bash
git clone https://github.com/XYZ921746/ElainaChat-mod.git
cd ElainaChat-mod
# 双击 启动.bat，或：
node web/serve.mjs
```

浏览器打开 `http://127.0.0.1:4173`。

| | 电脑版（Web） | 安卓版（APK） |

| Agent 文件操作 | ✅ 可读写电脑文件 | ❌ 手机没有这个能力 |
| AI 手机操作 | ❌ | ✅ 点击 / 滑动 / 输入 / 截图 |

| 两者可互相导入备份 | ✅ | ✅ |

## 扩展包（Mod / 插件）

程序本体只有**文字聊天 + Agent 能力**。其余呈现方式全是扩展包，按需安装。

当前共 **6 个扩展包**（前 4 个随仓库分发源码，后 2 个的图片资源走 Releases）：

| 扩展包 | 角色 | 依赖 | 说明 |
| --- | --- | --- | --- |
| `elaina-avatar` | 立绘资源 | — | 9 张立绘 + 情绪识别。**公共依赖**，被 galgame / pet 共用，无界面 |
| `scene-backgrounds` | 背景资源 | — | 31 张场景背景图（7.25 MB）。**公共依赖**，galgame 与视频通话共用，无界面 |
| `live2d-models` | 引擎与模型资源 | — | Live2D 运行引擎（787 KB，按需注入）+ **模型管理界面**（上传/重命名/删除，2×2 卡片） |
| `live2d` | 界面 | `live2d-models` | **Live2D 视频通话**：实时渲染、口型随真实音量、鼠标跟随、2×2 图片选模型 |
| `galgame` | 界面 | `elaina-avatar`、`scene-backgrounds` | 全屏剧情界面：打字机对话框、粒子特效，与主界面共用对话数据 |
| `pet` | 界面 | `elaina-avatar` | 桌宠悬浮层，回复时自动切表情 |

> **资源与代码分离**是刻意设计：`elaina-avatar`、`scene-backgrounds` 只提供资源与接口、
> 不提供界面 —— 它们被多个界面共用。放在某一个界面里会变成"想要背景就得启用剧情界面"，
> 而且卸载那个界面会把公共资源一起带走。
>
> 插件设置一律**独立成窗**（点插件卡片上的 ⚙ 齿轮），不占主设置的分栏 ——
> 插件一多，主设置里堆一排分栏既难找也难看。每个插件的设置窗口由插槽机制保管，
> 来回切换不会串台，重开是瞬开。

### 怎么安装

**方式一：应用内上传（推荐，手机也能用）**

1. 到 [Releases](https://github.com/XYZ921746/ElainaChat-mod/releases/latest) 下载需要的 `.zip`（**不要解压**）
2. 打开程序 → **设置 → 插件 → 上传安装** → 选中那个 zip
3. 安装完在列表里**打开对应的开关**

**方式二：丢进目录（电脑版）**

把 zip 直接放进 `web/mods/` 目录，然后在 **设置 → 插件** 点「重新扫描」。
服务端会自动解压 —— 不用解压、不用重启。

> 安装包在装好后会被**自动清理**。所以「删掉插件目录」就是有效的卸载方式，
> 不会被重新装回来。应用内也有「删除」按钮。
>
> **Live2D 模型**不是插件，走模型管理：设置 → 插件 → Live2D 引擎与模型 → ⚙ →
> 上传新模型（.zip）。

### 装完在哪用

| 扩展包 | 开启位置 | 使用位置 |
| --- | --- | --- |
| `elaina-avatar` / `scene-backgrounds` | 打开开关即可（无界面） | 被依赖的界面自动使用 |
| `live2d-models` | 打开开关 | 设置 → 插件 → ⚙ 管理模型 |
| `live2d` | 打开开关 | 顶部栏「视频通话」按钮 |
| `galgame` | 打开开关 | 主界面出现全屏剧情模式入口 |
| `pet` | 打开开关 | 桌面上出现悬浮角色 |

> **插件默认关闭**，装完要手动开。这是刻意的 —— 插件会改动界面，
> 不该在你不知情时生效。

### 自己写一个插件

插件就是一个目录 + 一份清单。宿主**不认识任何具体插件**，所以加功能不用碰主程序。

**最快的上手方式：复制模板** [`templates/mod-starter/`](templates/mod-starter/) ——
各插槽都有能跑的示例，同目录下还有一份更细的作者说明（生命周期、调试、手机端限制）。

```text
web/mods/my-mod/
├─ manifest.json     # 必需：id / name / version / entry / styles / defaultEnabled / after
├─ index.js          # 入口：用 ElainaMods.register(id, factory) 注册
├─ style.css         # 可选：自己的样式（停用时会真的失效，不是藏起来）
├─ panel.js / .html  # 可选：自己的设置界面（走 settings.modal 插槽，独立成窗）
└─ server.mjs        # 可选：自己的后端接口（只有电脑版有服务端，见下）
```

**能挂在哪**：宿主提供 6 个**插槽**，权威清单在 [`web/js/host-slots.js`](web/js/host-slots.js)：

| 插槽 | 形态 | spec |
| --- | --- | --- |
| `settings.tabs` | 挂载一次 | `{ id, label, render(container) }`（宿主自己的分栏用；插件默认不用它） |
| `settings.modal` | **独立设置窗** | `{ id, title, render(container) }` —— 插件设置的标准姿势，点卡片上的 ⚙ 打开 |
| `header.actions` | 挂载一次 | `{ id, label, title?, svg?, onClick }` |
| `sidebar.footer` | 挂载一次 | `{ id, render(container) }` |
| `composer.actions` | 挂载一次 | `{ id, render(container) }`（容器是 `display:contents`） |
| `chat.message.actions` | **每项级** | `{ id, render(container, { message, conversationId }) }` |

「每项级」= 宿主**每渲染一条消息就调一次**你的 `render`。你只往容器里加节点，
别清空容器、别碰别人的节点；宿主会给你加的元素打归属标记，停用时精确摘除。

设置窗插槽（`settings.modal`）给**每个插件一块专属容器**：渲染结果一直保留，
来回切换不串台、重开瞬开；停用插件时它的容器被一并摘除。

```js
// index.js —— 拿到宿主给的 api，别直接摸宿主内部
ElainaMods.register('my-mod', (host) => {
    host.log('已加载。可用插槽：' + host.slots().join('、'));

    // 插件设置：独立成窗（点插件卡片上的 ♂ 齿轮打开）
    host.slot('settings.modal', {
        id: 'my-mod', title: '我的插件',
        render(container) {
            container.innerHTML = '<section>…你的设置面板…</section>';
        },
    });

    // 顶部栏加一个按钮
    host.slot('header.actions', {
        id: 'hello', label: '打招呼',
        onClick: () => host.sendUserMessage('你好'),
    });

    // 往 system 提示词里追加一段（插件影响模型行为的唯一入口）
    host.setPromptHint('当用户提到「天气」时，用 <weather>…</weather> 包裹城市名。');

    // 订阅宿主事件（停用插件时宿主会自动退订，不用自己清）
    host.on('reply-done', (text) => host.log('AI 回复了', String(text).slice(0, 40)));

    // ★ 取自己的资源要用 host.assetUrl()，**不要**自己拼 '/mods/my-mod/…'
    //   插件声明的 id 与它被安装成的目录名**可能不同**。自己拼路径会在那时 404。
    const img = host.assetUrl('img/icon.png');   // → 永远指向真实位置

    // 在文件管理器里打开自己目录（或目录内的子路径）—— 仅本机可用
    // await host.openFolder();            // 自己的目录
    // await host.openFolder('models/x');  // 子路径（服务端逐段白名单校验）

    return {
        // 用户在插件列表里关掉它时调用 —— 把**你自建**的界面/定时器收起来
        setEnabled(on) { /* ... */ },
    };
});
```

> **生命周期三条**（写成别的样子会踩坑）：
> **工厂只跑一次**，所以里面只做注册 —— 别在工厂里发请求、起定时器、改别人的 DOM；
> **停用会收回你注册的一切**（插槽内容、注入的样式、system 提示词、事件订阅、消息行按钮）；
> **启用按同一份 spec 装回来，不会重跑工厂**。自建的界面/定时器由你的 `setEnabled` 负责收。

宿主 API 是一张**收窄的清单**（不是把 `window` 丢给插件）—— 这样宿主才能重构内部实现
而不弄坏插件。完整清单见 `web/js/mods.js` 的 `createHostApi()`：
`assetUrl` / `assetBase` / `require` / `openFolder` / `dragSort` / `getConversation` /
`getMessages` / `getUiMode` / `sendUserMessage` / `renderText` / `slot` / `slots` /
`injectStyle` / `setPromptHint` / `clearPromptHint` / `on` / `emit` / `has` /
`log` / `warn` / `error`。

其中两个值得单独说明：

- **`host.require('别的插件id')`** —— 取另一个插件注册时返回的 api
  （例如视频通话向 `live2d-models` 要引擎加载与模型列表）。目标插件没装/没启用时
  返回**带原因的失败对象**，不会抛异常；
- **`host.dragSort(container, onDone)`** —— 宿主实现的**列表拖拽排序**（卡片跟手、
  其它卡片换位动画、Esc 取消）。插件列表与模型列表用的是同一份实现，
  要排序的列表不必各写一套。

> **`manifest.json` 里请显式写 `id`。** 它是插件的**身份**：依赖它的 `after`
> 按这个名字匹配，你的资源 URL 也以它为准。不写时才会回落到目录名。

> **需要自己的后端接口**时，在清单里声明 `server: { entry, routes, uploads, static }`，
> 接口地址必须落在这份声明之内（声明与实现分离：用户看清单就知道插件要占哪些地址）。
> **只有电脑版有服务端** —— 手机（APK）上这一半永远不加载，依赖它的功能要能降级。

> **安装插件 = 信任它的代码**（它在页面同源环境里运行）。请只装自己信得过的。

### 为什么扩展包资源不放在仓库里

这些资源合计 **约 22 MB，其中 87% 是图片**（PNG / JPG / moc3）。
Git 对二进制**无法有效增量压缩** —— 改一张立绘，历史里就多存一整份，
clone 会越来越慢。所以：

* **整个 `web/mods/` 不入仓库**（2026-10 起，用户决定：仓库只推软件本体）——
  插件（含源码）与 Live2D 模型都由维护者用 `node scripts/pack-assets.mjs`
  打包后上传 Releases
* 宿主对"没有任何插件"有完整降级：设置里显示空列表 + 引导文案，
  Live2D 引擎库保留在 `web/vendor/`（软件本体的组成部分），插件缺失时回落可用
* `web/mods/live2d-models/models/` 下是你**本地装着**的模型（`gitignore` 排除），
  仓库里看到的目录结构不代表别人 clone 下来也有

自己改完插件后重新打包：

```bash
npm run pack:assets               # 打包全部（输出到 dist/assets/）
npm run pack:assets galgame       # 只打某一个
node scripts/pack-assets.mjs --list   # 先看看会打什么
```

打包格式有约定（写进脚本注释了）：插件 zip 的**根目录直接是文件**，
模型 zip 的**根目录必须是模型名那一层** —— 因为模型是按目录名识别的。

## 功能详解

### Live2D 视频通话

顶部栏「视频通话」进入全屏界面，角色以 Live2D 模型实时渲染。

**模型管理（在「Live2D 引擎与模型」的设置里）**：

- 2×2 **模型卡片**：缩略图 + 名字 + 表情/动作/体积统计；模型超过 4 个时区域内部滚动，
  第三行露出约一半提示下面还有
- **上传**：Cubism 3 模型压缩包（`.model3.json` + `.moc3` + 纹理），服务端解压；
  兼容 UTF-8 与 GBK 两种文件名编码（Windows 自带压缩工具的中文名 zip 常见问题）、
  带路径白名单防目录穿越、`.exe` 等可执行文件拒绝落盘
- **重命名**：直接改模型文件夹名（中文、空格都支持，重名自动加序号），该模型的
  缩放/水印设置一并迁移
- **打开模型文件夹**：卡片上的 📂 按钮，方便开发者直接改模型文件（仅本机可用）

**选择模型（在「Live2D 视频通话」的设置里）**：

- 2×2 **图片选择区**：模型图片 + 下方名字，选中的带「已选择」角标；
  右侧详情区随选中更新（表情/动作/体积/文件数）
- 点一下即切换，通话开着时**立刻换人**

**画面表现**：

- **按真实音量驱动口型**：用 Web Audio 的 `AnalyserNode` 读取 TTS 的实际音量驱动
  `ParamMouthOpenY`，而不是虚假的正弦波；无音量时回落
- **背景**：上传本机图片；想用现成场景图可装 `scene-backgrounds` 扩展包
  （装了会在设置里出现场景选择区，AI 也能用 `[背景:雪夜]` 这类标签选它们）
- **大小与位置调整框**：框体贴合模型实际绘制范围并逐帧跟随；每个模型独立记忆
- **鼠标跟随**：头部与眼珠追踪鼠标，幅度可调（0-10 标准范围，可解锁到 100）

**通用水印开关**：服务端在模型列表里返回表情清单，前端自动找出命名为
「水印 / watermark」的表情。通话中按键盘 `1` / `0` 切换，也可由 AI 用
`[操作:隐藏水印]` 触发。

**引擎按需加载**：Cubism Core / PIXI / pixi-live2d-display 三个库（合计 787 KB）
住 `live2d-models` 插件里，**首次打开通话才注入** —— 不用 Live2D 的用户不付这份代价。

### AI 标签协议

LLM 的回复里可以携带标签来驱动模型表现和应用功能，**这些标签不会显示给用户**。

| 标签 | 作用 |
| --- | --- |
| `[情绪:开心\|难过\|生气\|害羞\|惊讶\|委屈\|思考\|平静]` | 映射表情与嘴型幅度 |
| `[表情:xxx]` / `[动作:xxx]` | 播放指定表情 / 动作 |
| `[位置:left\|center\|right]` / `[大小:大\|小\|特大\|65%]` | 移动 / 缩放模型 |
| `[背景:深蓝\|雪夜\|...]` | 切换背景（先匹配场景背景资源包的真图，认不出回落预设色） |
| `[操作:打开视频通话\|整理记忆\|手机点击 500 800\|...]` | 执行应用内操作 / 文件操作 / 手机操作 |
| `[任务:每天 09:00 ...]` | 创建定时任务 |

**这套协议归宿主所有，不归 Live2D**。标签的**剥离**与 `[操作:…]` 的**分发**在
`web/js/agent-tags.js`（宿主自有）。这是踩过坑的架构决定：原先这两件事整个长在
Live2D 的文件里，而它是全部 `[操作:…]` 的唯一分发器 —— Live2D 一旦不在
（卸掉、或加载失败），**Agent 系统会整体失效**。现在 Live2D 只提供**表现**，
并通过 `registerOperationHandler` 把水印/静音这两个它独有的操作**追加**进分发链 ——
它可以扩展这条链，但不再拥有它。

**跨模型自适应**：模型列表接口返回每个模型可用的表情与动作文件名，系统提示词动态注入，
AI 直接选用真实文件名；情绪词经「语义映射 → 精确匹配 → 子串兜底」三级解析。

### 多套人设

- 设置 → 角色：**新建 / 复制 / 改名 / 删除**并随时切换
- **不会丢编辑**：切换时先把正在编辑的内容存回原人设
- **内置人设跟随仓库分发**，清数据也会自动补回；你的改动不会被覆盖
- **老数据自动迁移**：原本只有一张卡的用户，那张卡变成列表里的第一套

### 跨设备数据同步

原版数据存在浏览器 `localStorage`，每台设备各一份。本改版把需要共享的 11 项
（设置、API Key、聊天记录、分类、收藏、角色卡、记忆等）同步到服务端 `data/` 目录，
**按用途分类落盘**：

```text
data/
├─ store.json           设置 / API Key / UI 偏好
├─ characters/          人设卡 —— 一卡一文件（可单独拷走分享）
├─ conversations/       聊天记录 —— 一对话一文件
├─ memory/              记忆 —— 一类目一文件（diary / promise / preference / plan /
│                         motivation / pivotal_memory，增长特性不同所以分开）
├─ auth.json            局域网访问密码（scrypt 加盐哈希）
├─ cert.pem / key.pem   自签 HTTPS 证书
└─ logs/                每次启动一组日志（主 + 追踪），保留最近 10 次
```

**备份与恢复**：设置 → 高级 → 我的数据。导出标准 zip（电脑版与手机版可互相导入）；
导入默认合并模式 —— 只覆盖备份里有的项。

**刻意不同步的两项**：当前打开的会话（各设备独立）、模型尺寸记忆（跟屏幕有关）。

### 手机端与网络访问

- **一个端口同时认 http 和 https**：浏览器地址栏输 `IP:端口` 不用手动补 `s`。
  麦克风只在安全上下文可用（浏览器硬性规定），所以局域网 http 会自动跳 https；
  本机不跳。想强制留在 http：访问 `?stay=http`
- **自签证书自动管理**：首次启动自动生成（SAN 带所有局域网 IP），到期前 30 天自动续期；
  `--reset-cert` 可手动重签
- **手机访问**：`http://<本机局域网IP>:4173`，需要访问密码

### 语音输入与合成

- **输入**：阿里云百炼（`qwen3-asr-flash`）、小米 MiMo 可选，接口与模型名可配置；
  **彻底移除浏览器内置识别** —— 它连不上 Google 服务时会在约 1 秒内把整个浏览器进程带崩
- **合成**：MiniMax / 豆包 / 阿里千问 TTS（BYOK）+ **Edge TTS（免费，无需 Key）**。
  Edge TTS 的协议由电脑版本机服务代合成、安卓版走原生层 —— 浏览器 JS 发不了它要的请求头

### AI 定时任务

`[任务:每天 09:00 提醒我喝水]`、`[任务:30分钟后 ...]` —— 到点以角色身份自动发消息。
支持周期与一次性任务；设置 → 高级 可查看取消。

### Agent 文件操作

LLM 可用标签请求本地文件操作：`[操作:列出文件 路径]`、`[操作:查看文件 路径]`、
`[操作:保存文件 路径|内容]`。要点：

- **权限分两级**：默认「仅应用文件夹」；可选「允许操作电脑」（PowerShell / cmd）
- **权限边界只由"是否已登录"决定**：本机免密即管理员；局域网设备登录后同等能力。
  所以 **⚠️ 访问密码 = 这台电脑的钥匙**，请务必设强密码
- **两种模式都拦**：覆盖已有文件需确认（`needOverwrite`，每对话问一次）；删除类命令判危险
- **自动续跑**：一次操作成功后结果回灌模型决定下一步，多步任务自己走完
  （上限 8 步，随时可停；只有成功才续跑）
- **桌面不一定在 `C:\Users\<名字>\Desktop`**：服务端从注册表读真实位置，提供
  `%DESKTOP%` / `%DOCUMENTS%` / `%DOWNLOADS%` 别名
- **应用文件夹模式禁止写 `.html`/`.js`/`.svg` 等可执行类型**（防存储型 XSS；
  曾被 `x.html::$DATA` 这类 NTFS 写法绕过，已修）

### 视觉模型转述

设置 → 视觉 配置一个 OpenAI 兼容的视觉模型后：**视觉模型先看图转述成文字，
再交给主模型按角色回答**。没配置时图片直接发给当前模型。

### 访问控制与安全

服务默认监听 `0.0.0.0`（方便手机访问），因此：

- **本机免密**；**局域网必须登录**（HttpOnly Cookie 会话，登录后与本机同等能力）
- **首次启动生成随机密码**（12 位，排除易混字符）；改过之后只存 scrypt 加盐哈希
- **密码强度**：≥8 位含数字+大小写；拒弱口令表、键盘顺子
- **登录防爆破（三层）**：单 IP 指数退避（30 秒起翻倍，上限 1 小时）；
  计数只在成功时清零；全局限流（换 IP 绕不过）。被拦回 `429 + Retry-After`
- **CSRF 防护** + **Host 白名单**（防 DNS rebinding）+ 隐藏文件禁止静态访问 +
  解压路径白名单 + zip 体积上限
- **已知弱点（如实说明）**：全局冻结可被利用做拒绝服务（全局限流固有的代价）；
  失败计数与会话 token 在内存里，重启即清空

### BYOK 直连与本地中转

API Key 填在你自己的设备上，请求直连你指定的服务商。但浏览器有 **CORS** ——
自建网关、内测中转很多不发 CORS 头，`fetch` 只会抛一句 `Failed to fetch`。

**解决办法**：页面由 `serve.mjs` 提供时，前端自动改走同源的 `/api/relay`：

```
浏览器 ──同源──▶ 本机 Node 进程 ──▶ 你的服务商
        （无预检）      （Node 没有 CORS 这回事）
```

- Key 只经过本机进程内存，不落盘、不给第三方；探测不到中转（`file://` 打开）自动退回直连
- **安全边界**：需要登录；封禁云元数据地址（`169.254.169.254`）；回环地址限本机发起
  （SSRF 防护，含 `::ffff:127.0.0.1` 这类 IPv4-mapped IPv6 写法）
- **报错给具体原因**：连不上是什么原因（DNS / 超时 / 拒绝）、模型名不对直接提示去获取模型、
  识别 FastAPI 系网关的嵌套错误；开头连续的多条 system 自动合并（有些中转只收一条）

### 排查与诊断

- **日志落盘** `data/logs/`，格式参照 AstrBot（loguru）：
  `[时间] [模块] [级别] [来源:行号]: 正文`，五级 `DBUG/INFO/WARN/ERRO/CRIT`
- **每次启动一组两个文件**：主日志（一行一条，方便 `grep`）+ `.trace.log`
  （LLM 完整请求/回复/上游原始报错 —— 分开是让"要不要发对话内容"成为一个明确动作）
- **浏览器报错转发**到启动窗口，手机出问题不用看控制台
- **级别设置即时生效**（终端永远全量，文件按级别收窄）；请求头一律不记录
- 诊断页：`/diag-live2d.html`（引擎加载）、`/diag-asr.html`（识别）、
  `/diag-param-bind.html`（模型参数绑定扫描）

### AI 手机操作

让 AI **看见并操作手机**：点击、滑动、输入、读控件树、截图、启动应用。**仅安卓版**。

- **四种实现方式**：无障碍（免 root，唯一能可靠中文输入）/ Shizuku / Root / 模块
  （刷 KernelSU 模块，最强且不抢前台）
- **系统悬浮窗**：操作时屏幕浮小条 —— 随时停止、就地确认，不用切回应用
  （切回会让目标应用退后台导致操作失败，这是个真实踩过的死循环）
- **副屏监视窗**：模块后端跑在独立虚拟副屏上，可把画面实时搬进应用
- **敏感操作分级授权**：safe 直接放行 / sensitive 按策略 / dangerous（任意 shell）必问；
  「每次运行只确认一次」为默认
- 截图交给视觉模型转述后回灌主模型；没配视觉模型时建议改用「手机查看界面」

## 已知限制

### 数据备份

- **安卓版的导出/导入未在真机上实测**（只在模拟环境验证过调用路径）
- **导出文件包含 API Key 明文** —— 分享前务必自己检查
- **导入是按键覆盖式合并**，没有逐项 diff

### Live2D

- **参数绑定情况由模型作者决定**，换模型必须重新验证；可用 `/diag-param-bind.html` 扫描
- 带 `2` 后缀的角度变体（`ParamAngleX2` 等）语义不可靠，已排除不驱动
- 鼠标跟随的头部幅度受模型自身参数量程限制（多数约 1.5 倍到顶，更高由身体跟随补足）
- **模型缩略图依赖模型自带图标**：没有 `icon.png` 这类文件的模型显示名字首字占位
- 安卓端 Live2D 未实测；上传大 zip（>50 MB）内存占用较高

### 对话接口与网络

- **本地中转只在页面由 `serve.mjs` 提供时生效**（`file://` 直开不走中转）
- 从局域网用手机访问时，**宿主机必须能访问该服务商**；Node 的 `fetch` 不读系统代理变量
- **部分服务商的 `/v1/models` 拿不到**（无 CORS 头），此时手填模型名即可
- **上游报错文案可能误导**（如说 system 位置不对、实际是不收多条）——已做兼容；
  深挖时看同名 `.trace.log` 里的原始响应体
- 追踪日志含完整对话内容，**是隐私面**（请求头一律不记录；可关）

### Agent 与手机操作

- Agent 文件操作**只能在网页版用**（APK 没有服务端）
- **没有删除/重命名/移动权限**（文件接口层面就没有）；覆盖已有文件需确认
- `.html` 写入防护不是完整边界 —— **真正的边界是"要不要给命令执行"这个开关**
- AI 手机操作**只在安卓版可用**；悬浮窗权限要手动到系统设置开
- 副屏监视窗、Shizuku UserService 绑定等**真机表现未完全验证**（详见开发文档）

### 插件系统

- 插件在页面同源环境运行，**安装 = 信任它的代码**
- 插件的 `server` 半边只在电脑版加载；APK 上依赖服务端的功能要能降级
- 场景背景只有 `.jpg`（`url()` 固定拼 `.jpg`）；模型缩略图只认 png/jpg/webp
